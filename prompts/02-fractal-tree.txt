Build a self-contained HTML page that draws an animated fractal tree using an L-system on a Canvas.

Requirements:
- Single .html file. Inline CSS and JS only. No external resources.
- Render a recursive fractal tree on a <canvas>, generated from an L-system (axiom + rewrite rules) and drawn with turtle-style interpretation.
- Animate the growth: branches extend and the tree unfolds over time via requestAnimationFrame, rather than appearing instantly.
- A control panel with live sliders/inputs for at least: recursion depth, branch angle, length ratio between generations, and a randomness/jitter amount.
- Color the branches by depth (e.g. trunk to twigs gradient) and optionally add leaves or blossoms at the tips.
- A "Regenerate" button that redraws with the current settings and a fresh random seed.
- Keep it performant and stable at higher depths (avoid freezing the page).
- Use a pleasant background and color palette.
- Must be valid HTML5. Must not throw any JavaScript errors when loaded.

Come up with an original, beautiful design and be creative.
