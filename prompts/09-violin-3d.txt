Build a self-contained HTML page featuring a playable violin rendered as an interactive 3D model.

Requirements:
- Single .html file. Inline CSS and JS only. No external resources (no CDN, no external libraries, textures, or audio files). Use raw WebGL or CSS 3D transforms for the geometry, and the Web Audio API to synthesize sound.
- A recognizable 3D violin: body with upper/lower bouts, neck, fingerboard, scroll, bridge, and four strings. It should be lit and shaded so the 3D form reads clearly.
- The camera can be orbited with the mouse (drag to rotate, optionally scroll to zoom).
- The violin is playable: clicking or hovering a string (optionally combined with keyboard keys for pitches) plays a synthesized note via Web Audio, tuned to the four violin strings (G3, D4, A4, E5).
- Visual feedback when a string is played (e.g. the string vibrates or highlights).
- A small on-screen hint explaining how to play.
- Must be valid HTML5. Must not throw any JavaScript errors when loaded.

Come up with an original, visually appealing design and be creative.
